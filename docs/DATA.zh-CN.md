# 数据与构造

[English](DATA.md) | [简体中文](DATA.zh-CN.md)

OptionFlow使用DCE、CZCE、SHFE、INE和GFEX的官方历史期权、期货下载文件。输入快照共588份文件，基础日期覆盖2017—2025年；研究面板使用2019年起的信号和截至2025-12-31的收益。[source_manifest.csv](../config/source_manifest.csv)记录相对文件名、字节数和SHA256，仅含文件元数据，不含行情观测。

## 构造规则

1. 识别交易所、商品、完整交割年月、期货类别、期权系列、看涨/看跌及行权价。来源文件、工作表、行号和指纹记录追溯关系。三位交割代码在受交易年份约束的十年窗口内解析。
2. 成交量、持仓量统一为单边手数。本下载文件族中，大商所始终乘0.5；郑商所、上期所、能源中心2020年前乘0.5，之后乘1；广期所乘1。该规则针对本下载文件族，不能推广到交易所所有接口。价格不变。
3. 主分析只用普通期货和常规期权；月均价F期货、MS期权单独保留。
4. 每个商品选当日成交量最大的正成交量普通期货；并列时依次按持仓量、较早交割月、稳定合约编号排序。先选合约，再检查期权与目标收益可用性；匹配失败不换另一个合约。
5. 先分别加总看跌和看涨数量，再相除，得到合约月份与商品口径的成交量、持仓量PCR。分母为0记缺失；分母为正时，分子为0是有效值。
6. 收益要求相邻预期交易日两端均实际成交且收盘价为正；次日仍用信号日选定的同一合约。公告收盘价、结算价变体单独保留，不用其他价格定义填补主收益。
7. 月份PCR在同一合约内滞后，商品PCR在商品内滞后，不跳过缺失的预期交易日，也不用上一个保留的主力行替代。
8. 按收益日划分：2019—2024为开发期，2025为评估期。覆盖、流动性和有限数值要求形成非平衡共同样本。

日历使用跨交易所观测及固定版本XSHG代理日历。系列末观察日仅为诊断标签，不等同于已认证官方到期日，也不用于预测。合约规则与日终信息发布时间限制交易层面的解释。
